# 模型 v3：10 物种 / 44 类

> 承接 `docs/25`。本次使用桌面上的三个 Mendeley 分卷 ZIP 扩展病害类别。

## 1. 数据来源与范围

三个 ZIP 来自同一完整数据集：

- Mendeley Data DOI: `10.17632/2vzp6ss7vg.1`
- License: CC BY 4.0
- 完整数据集: 4,479 张
- 物种: 月季、扶桑、万寿菊

压缩包中的 `Rosa/Rosa`、`Hibiscus rosa-sinensis/Hibiscus rosa-sinensis`、
`Tagetes erecta/Tagetes` 三个目录抽查后确认是花朵或花苞，不是叶片健康/病害状态，
因此排除，共 487 张。

实际进入训练的数据为 **3,992 张 / 3,876 个原图组**。

## 3. 数据准备

```powershell
python ai-service/train/prepare_mendeley_v3.py `
  --zip "$env:USERPROFILE\Desktop\plant-disease-wechat-part1.zip" `
  --zip "$env:USERPROFILE\Desktop\plant-disease-wechat-part2.zip" `
  --zip "$env:USERPROFILE\Desktop\plant-disease-wechat-part3.zip" `
  --out experiments\data\mendeley_v3 --max-side 448
```

脚本做三件事：

1. 只保留有明确健康/病害标签的目录；
2. 将图片最长边缩放到 448 px；
3. 将原图、`no_bg_` 版本和 `_1` 副本归到同一个原图组。

## 4. 通用模型训练

```powershell
python ai-service/train/train_indoor.py `
  --data D:\indoor-plant-data\combined_v2 `
  --extra-data experiments\data\mendeley_v3 `
  --out experiments\data\general_v3 `
  --arch mobilenetv3_large_100 --img-size 160 --epochs 20 --batch 64 `
  --lr 2e-3 --cap 800 --workers 0 --group-split 1 --pretrained 0 `
  --init-checkpoint D:\indoor-plant-data\general_v2\best.pt `
  --bg-random 0.15 --bg-dir D:\indoor-plant-data\main --auto-crop 1
```

合并后 17,389 张；按 800 张/类限流后 16,218 张；
按原图组切分为 train 11,375 / val 2,422 / test 2,421。

## 5. 月季专用模型

通用模型在月季新增类上存在明显混淆，因此增加 10 类专用模型：

```powershell
python ai-service/train/train_indoor.py `
  --data D:\indoor-plant-data\combined_v2 `
  --extra-data experiments\data\mendeley_v3 `
  --class-prefix Rose_ `
  --out experiments\data\rose_v3 `
  --arch mobilenetv3_large_100 --img-size 224 --epochs 18 --batch 64 `
  --lr 1.5e-3 --cap 800 --workers 0 --group-split 1 --pretrained 0 `
  --init-checkpoint experiments\data\general_v3\best.pt `
  --bg-random 0.15 --bg-dir D:\indoor-plant-data\main --auto-crop 1
```

服务按 `species=Rose` 自动路由到 `models/specialized/rose/`。

## 8. 已知限制

- 新增数据主要来自单一公开数据集和白色背景叶片特写，不能替代真实手机场景评估。
- 月季营养缺乏与健康、黑斑等症状仍有混淆，专用模型 Top-1 只有 63.16%。
- 万寿菊虫害测试样本只有 10 张，80% 的逐类结果波动较大。
- 花朵目录被主动排除，模型不把“开花的月季/扶桑/万寿菊”识别为健康状态。
- 对未覆盖病害仍可能高置信度误判，前端应继续显示该物种的类别覆盖范围。
